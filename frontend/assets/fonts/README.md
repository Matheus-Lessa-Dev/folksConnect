# Fontes Folks Mobile

Familias confirmadas nas propriedades das camadas do Figma Folks Mobile:

- Inria Serif Bold: titulos e cartoes.
- Inter Regular/Bold: textos auxiliares, categorias, colunas e seletor Kanban/Lista.
- Inria Sans Regular: sinal de adicionar. A familia tambem foi identificada entre os recursos do arquivo, incluindo o peso Bold.

Os TTFs redistribuiveis foram obtidos do repositorio oficial Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/inriasans
- https://github.com/google/fonts/tree/main/ofl/inriaserif
- https://github.com/google/fonts/tree/main/ofl/inter

Licencas incluidas: `OFL-InriaSans.txt`, `OFL-InriaSerif.txt` e `OFL-Inter.txt`.

Os nomes das familias/pesos foram confirmados no Figma; nao foi possivel comparar byte a byte os arquivos internos do Figma com os arquivos publicos do Google Fonts.
